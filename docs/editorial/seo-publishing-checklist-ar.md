# قائمة تحقق النشر التحريرية وSEO

تُراجع هذه النقاط قبل نشر الخبر أو اعتماد تعديل جوهري. لا تستبدل المراجعة الصحفية ولا تضيف مصادر تلقائيًا.

- العنوان والمقدمة يصفان ما تثبته المادة، ويظهر الحدث والجهة والمكان والزمن عند الحاجة.
- كل رقم أو اقتباس منسوب إلى مصدر واضح؛ تُدرج روابط المصادر التي راجعها المحرر فقط.
- نوع المادة صحيح: خبر، رأي، تحليل، إنفوجرافيك أو مادة مرئية.
- اسم الكاتب أو الجهة الناشرة صحيح، ورابط الملف العام يعمل.
- الصورة البارزة لها وصف بديل مناسب، ومصدرها وإفصاح الصورة المولدة آليًا صحيحان.
- تاريخ النشر محفوظ؛ لا يُعاد ضبطه عند الإنعاش. يُسجل «آخر تحديث» فقط عند تغيير تحريري ذي معنى.
- يمكن فهم الخبر من HTML والمتن حتى عند تعذر تحميل تضمين خارجي.
- بعد النشر تُراجع صفحة الخبر العامة والعنوان والتاريخ والصورة والروابط الأساسية.

المصادر التي يقترحها المساعد مسودات. لا تُضاف إلى المتن إلا بعد فتحها ومراجعتها واختيارها صراحة.
