# جاهزية اكتشاف الأخبار — تنفيذ تدقيق 8 سبتمبر 2026

متابعة: #1558. النطاق: HTML العام ومسار تحريره وبيانات SEO؛ لا Schema جديد ولا تغيير لعقود التطبيقات أو أخبار الإنتاج أو سياسة التدريب.

## معايير القبول
- لا يعيد الزاحف 200 بقالب SPA فارغ عند تعطل SSR والميتادات؛ يعاد 503 وRetry-After وno-store. 404/410 الحقيقي محفوظ.
- صور JSON-LD قابلة للتحميل، وهوية الكاتب المؤسسي تختلف عن الشخص، وروابط الكاتب تشير لسطح موجود.
- الرأي والتحليل ووصف الصورة وإفصاح التوليد والتاريخ الميلادي بتوقيت الرياض تصل إلى SSR.
- `seoMetadata.editorialModifiedAt` تاريخ تحريري يكتبه الخادم بعد اختلاف حقول عامة؛ `updatedAt` يبقى للحفظ. لا تعاد كتابة تواريخ الأخبار القديمة بالتخمين. المواد القديمة التي ليس لها سجل تحريري موثوق تستخدم تاريخ النشر في Schema؛ لا backfill آلي.
- الأرشيف العربي يستخدم صفحات 30 مادة بروابط السابق/التالي وcanonical مستقل؛ الكاتب 18 مادة من خدمته العامة الموجودة. الحد التشغيلي للصفحات 10000 لمنع offsets غير محدودة. لا تعني الروابط ضمان الفهرسة.

## الحداثة والكاش
- Next لا يعيد استخدام Data Cache قديم؛ API يحمي القراءة بكاش محدود وsingle-flight.
- إبطال النشر يغير جيل كاش SEO محليًا وعبر Redis؛ الرد الجاري الذي يعبر التغيير لا يكتب أو يقدّم نسخة قديمة.
- purge يشمل bundles، لكن لا يُعد تطهير الرابط المعتاد برهانًا على إزالة كل مفاتيح Pages المخصصة. HTML والميتادات لهما مدة قصيرة دون stale-while-revalidate؛ مدد الطبقات قد تتراكب. لا يوجد SLA إنتاجي مثبت قبل الاختبار التالي.
- اختبار قبول النشر، بعد تفويض الإنتاج: خبر اختباري معتمد، تغيير جملة وتصحيحها، طلبات قليلة مؤرخة للقارئ والزواحف خلال انتقال الكاش؛ تسجيل النص وdateModified وx-edge-cache وHTTP. إعادة الاختبار مع انقطاع Redis في بيئة اختبار، دون إجراء ذلك على الإنتاج.
- أهداف القياس تُحدّد بعد خط الأساس؛ لا وعود بفهرسة خلال 15 دقيقة أو نمو ثابت في الظهور.

## سياسة البحث والتدريب
التوصية المحافظة: بقاء سياسة منع التدريب الحالية، وإتاحة المحتوى العام لزواحف البحث المسموح بها. تحديث تصنيف الزواحف في الكود لا يغير robots أو WAF. التحقق من IP مطلوب لإثبات مرور الزاحف الحقيقي.

- OpenAI: https://developers.openai.com/api/docs/bots
- Google AI Search: https://developers.google.com/search/docs/appearance/ai-features
- Google Indexing API: https://developers.google.com/search/apis/indexing-api/v3/using-api

Google Indexing API لا يستقبل الأخبار العامة في مسار النشر بعد هذا الإصلاح؛ IndexNow إشعار للمحركات الداعمة ولا يثبت فهرسة. llms.txt وSchema خاصان ليسا شرطًا للظهور في Google AI Search.

## القياس
1. Search Console: عينات URL Inspection، الفهرسة وcanonical وآخر زحف؛ الظهور والنقرات منفصلان عن الاستشهاد.
2. Bing Webmaster Tools: AI Performance إذا أتيح للحساب؛ لا تعد الاستشهادات نقرات.
3. GA4: مصدر/وسيط الجلسة وصفحة الدخول للإحالات المعروفة، مع إبقاء direct/unknown غير محسوم.
4. سجلات زواحف متحقق من IP: HTTP والمدة وحالة الكاش، دون حفظ أسرار أو بيانات مستخدمين.
5. سجل يدوي أسبوعي لأسئلة عربية ثابتة: المنصة/الوضع/التاريخ والسؤال الحرفي والاستشهاد والصفحة وصحة الادعاء والتاريخ. لا إرسال آلي أو زحف كثيف.

## قرارات مؤسسية منفصلة
- أي تغيير لحقوق التدريب أو Google-Extended يحتاج قرارًا صريحًا؛ لا تغيير في هذه الدفعة.
- صياغة سياسة تصحيح وإسناد ومحتوى مدفوع علنية تعتمدها هيئة التحرير قبل نشرها. هذا المستند دليل داخلي وليس ادعاء بوجود إجراء مؤسسي مطبق.
- توحيد SSR لجميع القراء قرار معماري مستقل؛ هذه الدفعة تصلح البنية الحالية.

## تحقق التنفيذ المحلي
- نجحت مجموعة Vitest كاملة: 161 ملفًا و1238 اختبارًا، إضافة إلى اختبارين لعرض ArticleView ضمن إعداد مستقل لـNext.
- نجح TypeScript للجذر وNext، وبناء Vite والخادم وبناء Next باستخدام API محلي ببيانات اختبار. ESLint للملفات المتغيرة: صفر أخطاء، مع تحذيرات موجودة في الملفات الكبيرة.
- فحص Chromium فعلي: صفحة رأي SSR بتاريخ يعبر منتصف الليل، وصف الصورة وإفصاحها، وأرشيف القسم في Next والواجهة الحالية، وصفحة الكاتب الثانية وروابط التنقل وcanonical. لم تظهر أخطاء JavaScript غير معالجة في فحص صفحتي الواجهة الحالية. أصول الشعار في Next تعتمد على توجيه الإنتاج ولم تكن متاحة في الخادم المحلي.
- مراجعة مستقلة للفرق لم تجد مانع دمج. تمت معالجة خطر الكتابتين المتزامنتين بمقارنة ودمج JSONB داخل UPDATE واحد.
- لم يشمل هذا التحقق قاعدة بيانات الإنتاج أو WAF أو زواحف ذات IP موثق أو نتيجة URL Inspection أو انتقال الكاش على الإنتاج. يلزم اختبار القبول بعد النشر لإثبات هذه النقاط.
