# دليل خدمات منصة سبق الذكية الشامل

---

## أولاً: الواجهة العامة (ما يراه القارئ والمستخدم)

### 1. الأخبار والمحتوى الأساسي
- الصفحة الرئيسية (عربي / إنجليزي / أوردو)
- صفحة تفاصيل الخبر مع إحصائيات القراءة والتفاعل
- تصفح الأخبار حسب التصنيفات
- دليل التصنيفات الكامل مع إحصائيات كل تصنيف
- موجز الأخبار (News Feed)
- البحث بالكلمات المفتاحية والوسوم
- قسم الرأي والمقالات (صفحة عامة + صفحة لكل كاتب)
- الأخبار القصيرة (Shorts) — محتوى سريع بتنسيق عمودي
- النسخة الخفيفة (Lite Mode) — تحميل أسرع لأصحاب الاتصال الضعيف
- أرشيف المحتوى القديم

### 2. حساب المستخدم والملف الشخصي
- تسجيل حساب جديد
- تسجيل الدخول (عادي + تسجيل الدخول عبر Replit)
- استعادة كلمة المرور
- التحقق من البريد الإلكتروني
- الملف الشخصي (عرض وتعديل)
- الملفات الشخصية العامة للمراسلين والكُتّاب
- مركز التفضيلات (المظهر، اللغة، إعدادات المحتوى)
- إدارة الاهتمامات (اختيار المواضيع المفضلة لتخصيص المحتوى)
- متابعة الكُتّاب والمراسلين
- حفظ الكلمات المفتاحية المفضلة
- تجربة الإعداد الأولي للمستخدمين الجدد (Onboarding)

### 3. التفاعل والمشاركة
- نظام التعليقات على الأخبار
- نظام الإعجابات (Reactions)
- حفظ الأخبار في المفضلة (Bookmarks)
- مشاركة الأخبار على وسائل التواصل
- تسجيل تقدم القراءة (Reading Progress)
- سجل القراءة (Reading History)

### 4. خدمات ذكية وتفاعلية
- المُقترَب — منصة مشاركة المحتوى من القرّاء مع إمكانية تقديم زوايا إخبارية
- المِرقَب — أداة رصد ومؤشرات إخبارية عامة (مؤشر سبق، التنبؤ بالقصص)
- النشرات الصوتية — ملخصات أخبار صوتية
- عُمق (التحليل المعمّق) — تقارير وتحقيقات تفصيلية مع إحصائيات
- الموجز اليومي — ملخص يومي شامل لأهم الأحداث (عربي + إنجليزي)
- التغطية اللحظية (لحظة بلحظة) — تحديثات حية مباشرة
- التغطية الخليجية الحية
- متجر الوسائط — سوق أصول إعلامية
- المساعد الصوتي — تصفح الموقع بالأوامر الصوتية
- الروابط الذكية — صفحات تفصيلية للكيانات والمصطلحات المرتبطة بالأخبار

### 5. بوابة الإعلانات (الخدمة الذاتية)
- صفحة هبوط للمعلنين
- تسجيل حساب معلن
- تسجيل دخول المعلنين
- إنشاء حملات إعلانية

### 6. صفحات المعلومات
- من نحن
- اتصل بنا
- سياسة الخصوصية
- شروط الاستخدام
- بيان إمكانية الوصول
- صفحة المطورين
- سياسة الذكاء الاصطناعي
- خلاصات RSS

## ثانياً: لوحة التحكم (Dashboard) — الإدارة والتحرير

### 1. الصفحة الرئيسية للوحة التحكم
- نظرة عامة على حالة النظام
- إحصائيات سريعة (عدد المقالات، المستخدمين، التفاعلات)
- إجراءات سريعة

### 2. إدارة المحتوى
- إدارة الأخبار والمقالات (عرض، إضافة، تعديل، حذف)
- محرر المقالات المتقدم مع معاينة مباشرة
- إدارة التصنيفات (إنشاء، تعديل، ترتيب، حذف)
- إدارة الوسوم (Tags)
- إعادة ترتيب التصنيفات بالسحب والإفلات
- نظام حالات المقال (مسودة، قيد المراجعة، منشور، مؤرشف)

### 3. إدارة المستخدمين والصلاحيات
- إدارة المستخدمين (عرض، تعديل، حظر)
- إدارة الأدوار والصلاحيات (إنشاء أدوار مخصصة)
- إدارة فريق العمل (الموظفين)
- نظام صلاحيات دقيق (مثل: analytics.view، breaking_ticker.manage، categories.create)

### 4. إدارة المراسلين والكُتّاب
- طلبات المراسلين — مراجعة وقبول/رفض طلبات الانضمام
- طلبات كُتّاب الرأي — فحص واعتماد المتقدمين
- إدارة الناشرين الخارجيين

### 5. التحليلات والإحصائيات
- لوحة التحليلات العامة
- تحليلات المقالات (أداء كل مقال)
- تحليلات سلوك المستخدمين
- تحليلات المشاعر (Sentiment Analytics)
- تحليلات التخصيص (Personalization Analytics)
- رؤى يومية ذكية مولّدة بالذكاء الاصطناعي للإدارة

### 6. الاتصالات والإشعارات
- مركز الاتصالات (بديل واتساب والبريد الإلكتروني)
- إدارة الإشعارات الفورية (Push Notifications)
- تكامل مع Twilio للرسائل النصية

### 7. إدارة الإعلانات
- إدارة الإعلانات العادية
- إدارة الإعلانات المدمجة (Native Ads)
- تقارير أداء الحملات

### 8. أدوات المِرقَب (للمحررين)
- مؤشر سبق الإخباري
- التنبؤ بالقصص القادمة (Next Stories)
- الرادار الإخباري
- إنشاء عناصر مِرقَب جديدة

### 9. رؤى إمكانية الوصول
- تقارير عن مدى توافق المحتوى مع معايير الوصول
- اقتراحات تحسين

### 10. إعدادات النظام
- إعدادات عامة للمنصة
- إعدادات التخزين المؤقت (Cache)
- إعدادات الأمان (CSRF، حدود الاستخدام)

## ثالثاً: نظام iFox (الذكاء الاصطناعي لإدارة المحتوى)

### 1. لوحة تحكم iFox
- نظرة عامة على نشاط الذكاء الاصطناعي
- حالة المهام والإنتاج

### 2. إدارة الذكاء الاصطناعي
- تفضيلات الذكاء الاصطناعي (اختيار النماذج، ضبط المعايير)
- التقويم التحريري الذكي
- إدارة الميزانية (Budget Manager) للاستخدام
- قواعد سير العمل الآلي (Workflow Rules)
- فحوصات الجودة (Quality Checks)

### 3. توليد المحتوى بالذكاء الاصطناعي
- مولّد المقالات — إنشاء مقالات كاملة بالعربية والإنجليزية والأوردو
- دعم أنواع متعددة: خبر، تحليل، تقرير، مقابلة، رأي
- دعم نبرات مختلفة: رسمية، عامية، استقصائية، محايدة
- توليد مسودات من أحداث التقويم التحريري
- جدولة مهام التوليد الآلي

### 4. إدارة مهام الذكاء الاصطناعي
- عرض المهام المعلقة والمنجزة
- تنفيذ المهام المجدولة تلقائياً
- متابعة حالة كل مهمة

## رابعاً: خدمات الذكاء الاصطناعي (تعمل في الخلفية)

### 1. توليد وتحرير الصور
- استوديو الصور بالذكاء الاصطناعي (Image Studio)
- توليد صور إخبارية واقعية أو توضيحية من عنوان وملخص الخبر
- التوليد التلقائي للصور عند نشر الأخبار
- صور مصغرة ذكية (Smart Thumbnails) — تحسين تلقائي
- بطاقات مشاركة اجتماعية (Social Cards) — تصاميم جاهزة للمنصات
- كشف النقطة البؤرية في الصور لقص أفضل (Focal Point Detection)
- استوديو الإنفوجرافيك — توليد رسوم بيانية من البيانات

### 2. التصنيف والتحليل الذكي
- تصنيف المقالات تلقائياً مع نسبة ثقة وتبرير
- استخراج الكيانات (أشخاص، أماكن، مؤسسات) من النصوص
- توليد روابط ذكية تلقائياً داخل المقالات
- تحليل المشاعر في التعليقات والمحتوى

### 3. الترجمة والتلخيص
- ترجمة احترافية صحفية بين العربية والإنجليزية والأوردو (ولغات أخرى)
- تلخيص المقالات بجودة عالية
- إعادة صياغة المحتوى وتحسينه

### 4. توليد العناوين والمحتوى
- توليد 3 عناوين مختلفة لكل خبر
- تحليل وتوليد بيانات تحسين محركات البحث (SEO) تلقائياً
- توليد كلمات مفتاحية مقترحة

### 5. المساعد الذكي والمحادثة
- مساعد محادثة ذكي (AI Chat) يساعد القرّاء في البحث عن المعلومات
- يستند إلى آخر الأخبار المنشورة للإجابة على الأسئلة

### 6. التحقق والمصداقية
- تحليل مصداقية المقالات (مصادر، توازن، دقة) مع تقييم رقمي
- نظام تحقق متعدد النماذج (OpenAI + Claude + Gemini) للتأكد من صحة المعلومات

### 7. مراقبة المحتوى
- فحص التعليقات تلقائياً لكشف المحتوى المسيء أو غير اللائق
- تصفية تلقائية مع إمكانية المراجعة اليدوية

### 8. تحليل الاتجاهات
- رصد المواضيع الرائجة من بيانات المقالات والتعليقات
- تحليل المشاعر العامة تجاه المواضيع

## سابعاً: الأمان والأداء

### الأمان
- حماية CSRF مع نظام احتياطي (Double-Submit Cookie)
- نظام صلاحيات متعدد المستويات (أدوار + أذونات دقيقة)
- حماية البيانات — اختيار ضيّق للأعمدة (لا تسريب كلمات مرور أو رموز)
- تحديد معدل الطلبات (Rate Limiting)

### الأداء
- تخزين مؤقت ذكي متعدد المستويات (SWR + Memory Cache)
- اختيار أعمدة مُحسَّن (Narrow Selects) لتقليل تكلفة قاعدة البيانات
- تخزين سجلات السلوك مؤقتاً وكتابتها دفعة واحدة (Buffer + Bulk Insert)
- إلغاء تكرار سجل القراءة
- رؤوس تحكم في التخزين المؤقت (Cache-Control Headers)
