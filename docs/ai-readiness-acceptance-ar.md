# معيار قبول جاهزية سبق للذكاء الاصطناعي — الإصدار 1

تاريخ تثبيت المعيار: 2026-10-21. المالك: platform بالتعاون مع التحرير.

## القرار والنطاق

الهدف **98/100 على الأقل مع نجاح جميع البوابات الحرجة** أدناه. هذه درجة داخلية لقراءة الأخبار العامة واكتشافها وفهمها؛ ليست شهادة عالمية ولا ضمانًا للترتيب أو الاستشهاد أو الزيارات. لا تقارن مباشرة بدرجة Piperic أو عداد Cloudflare؛ لكل أداة نطاق وأوزان مختلفة.

هوية الزاحف تثبت بإشارات Cloudflare الموثوقة أو آليات المزود؛ User-Agent يختار طريقة العرض فقط ولا يمنح صلاحية. استخدام حساب القارئ نيابة عنه يحتاج لاحقًا إجراءات محددة وموافقة المستخدم وصلاحيات محدودة قابلة للإلغاء. لا تضيف هذه الحزمة دخولًا للوكلاء أو تجارة لرفع الدرجة.

## الحساب والدليل

- الحالة: ناجح، فاشل، غير متحقق. الناجح فقط يأخذ وزنه كاملًا. الفاشل وغير المتحقق صفر؛ لا يحذفان من المقام ولا تمنح نقاط لمجرد وجود الكود.
- المجموع 100. القبول يتطلب ≥98 ونجاح جميع البنود ذات ★. الدرجة تغطي العينة المحددة وليست ادعاء بفحص كل الأرشيف.
- كل بند يربط دليلًا مؤرخًا ونوعه وحدوده، مع SHA لخدمتي Pages وAPI وإعداد Markdown وSSR. `/api/version` يثبت API وحده.
- عند نقص أدلة الإنتاج تعرض الحالة «قيد القبول». يجوز عرض مجموع النقاط المثبتة مع النواقص، دون تسميته نسبة توافق فعلية.
- لا تغير الأوزان أو تستبعد فشلًا بعد رؤية النتائج؛ تعديل المعيار يصدر نسخة جديدة مع السبب.

## العينة وتنفيذ القبول

1. ثبّت العينة قبل الاختبار: الرئيسية، قسم نشط، 10 أخبار عربية تشمل حديثًا ومصححًا وأرشيفيًا ورأيًا/تحليلًا إن وجدا، 3 EN و3 UR منشورة إن توفرت، كاتب عام، صفحات الناشر والسياسة ومسار مفقود. سجل عدم توفر نوع دون اختراع محتوى.
2. اجلب HTML وMarkdown وتحقق من الحالة والترويسات والعنوان والمتن والروابط والتواريخ والبيانات المنظمة. اختبر HTML المفضل وMarkdown المرفوض بـq=0 وHEAD. لا يكفي HTTP 200.
3. استخدم محلل الصيغة المناسبة: نص robots، XML للخرائط/RSS، JSON للخلاصة. llms.txt ملف مساعدة اختياري وليس شرط Google أو شهادة AI.
4. راجع Cloudflare AI Crawl Control وWAF وسجلات الزوار الموثقة ثم URL Inspection. curl باسم بوت يختبر العرض فقط؛ 403 لهذا الطلب لا يثبت حجب المزود الحقيقي.
5. اختبر الأعطال والخصوصية والكاش في بيئة معزولة دون تعطيل الإنتاج أو إنشاء محتوى تجريبي فيه. لا تلغ حماية WAF لإجبار أداة على النجاح.
6. سجل لكل بند الحالة والدليل ووقت UTC والعينة وSHA والخدمة والناقص والمسؤول. أعد التحقق بعد النشر أو تغير إعداد مؤثر.

## خط الأساس — 2026-10-21

أدلة قبل هذه الحزمة؛ ليست قبولًا للنسخة الجديدة:

- Cloudflare يعرض Quick Wins = 5/5 وMarkdown for Agents مفعّلًا. عينة الأداة تعلن 200 وtext/markdown، لكن المقتطف الظاهر لا يثبت اكتمال متن خبر.
- طلبات مستقلة للرئيسية وخبر، بصيغتي HTML وMarkdown، واجهت 403 وcf-mitigated: challenge. وصول الزواحف الحقيقية غير متحقق حتى دليل الهوية والسجل.
- robots وllms والخرائط وRSS وJSON Feed كانت متاحة. فهرس الخرائط XML صالح يضم 524 رابطًا، وNews sitemap 312 خبرًا، وJSON Feed 50 عنصرًا؛ العدد وصف للعينة لا ضمان لجودة كل رابط.
- تطابق عنوان خبر في RSS وSEO-meta كشف اختلاف رابط RSS العربي عن canonical القصير. SEO-meta ليس دليلًا على HTML الذي تلقاه الزاحف.
- الكود كان يعلن Content-Signal في robots دون ترويسة HTML في Pages، وبعض وكلاء الاسترجاع خارج اختيار SSR. يعالج الإصلاح ذلك، لكن الاختبار المحلي لا يثبت نشره.
- موصل GSC Wizard رفض القراءة لعدم اشتراك نشط؛ لم نحصل منه على URL Inspection أو بيانات Bing. يمكن استكمالها من اللوحات الأصلية ولا يلزم شراء اشتراك لإصلاح الموقع.

**الحالة: قيد القبول، لا توجد نسبة 98% مثبتة.**

## حدود الحزمة والاستكمال

الحزمة الأولى تصلح ترويسات السياسة، اختيار المحتوى الكامل للوكلاء/Markdown، وروابط الخلاصات وسلامة XML. لا تغير سياسة التدريب أو WAF أو صلاحيات حسابات القراء. بعد PR ونجاح CI وطلب دمج صريح: تحقق نشر Pages وAPI ثم أعد العينة وأكمل أدلة الزواحف وSearch Console. كل فجوة متبقية تعالج بإصلاح محدد ودليل قبول.

الظهور والاستشهاد والزيارات من AI مؤشرات نتائج مستقلة عن الجاهزية التقنية، ولا يمكن ضمان قرارات محرك خارجي.
