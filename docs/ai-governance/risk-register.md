# سجل مخاطر الذكاء الاصطناعي

**الإصدار:** 1.0 — 2026-08-18 · يُحدَّث مع كل إغلاق أو استجداد، ويُراجع في
كل اجتماع للجنة الحوكمة. التصنيف وفق سلم سدايا؛ «الحالة»: مغلق / مخفَّف / مفتوح.

## مخاطر مغلقة (مرجعها PR ‏#1449 — 2026-08-18)

| # | الخطر | الإغلاق |
|---|---|---|
| C1 | نشر iFox الآلي بلا مراجعة ومفاتيح حوكمة غير موصولة | `resolvePublishDecision`: مسودة افتراضيًا + بوابة جودة |
| C2 | نقطة تحويل نص-لصوت بلا مصادقة (استنزاف مالي) | حُذفت؛ البديل نص مبني في الخادم من محتوى منشور |
| C3 | عدّاد تعديلات الذكاء في جواز المحتوى صفر دائمًا (بخس إفصاح) | تصحيح مصدر الاستعلام إلى `activity_logs` |
| C4 | لا قناة معالجة للمتضررين من الرفض الآلي | مسار اعتراض كامل + إفصاح «قرار آلي» في الإشعار |
| C5 | تناقض ادعاءات الميثاق المعلنة مع التطبيق | مواءمة نصوص `/sabq-ai` مع الواقع |

## مخاطر متأصلة مقبولة (تُراقب)

- **هلوسة النماذج** في أي توليد نصي — تُضبط بالمراجعة البشرية والدساتير
  وبوابات الجودة؛ لا تُقبل في محتوى ينشر آليًا بلا بوابة.
- **انقطاع مزود** — سلاسل بدائل + قاطع دارة + تنبيهات فورية.
- **انحراف تكلفة** — مراقبة اللوحة حاليًا؛ يُغلق جذريًا مع R2.
