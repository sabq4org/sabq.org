# حزمة حوكمة الذكاء الاصطناعي في سبق

**الإصدار:** 1.0 — 2026-08-18 · **الحالة:** معتمدة إداريًا بتاريخ 2026-08-18

هذه الحزمة هي المرجع الرسمي لحوكمة أنظمة الذكاء الاصطناعي في منصة سبق، وأُعدَّت
استيفاءً لمتطلبات **اعتماد مقدمي خدمات الذكاء الاصطناعي** لدى الهيئة السعودية
للبيانات والذكاء الاصطناعي (سدايا) — وسم «واعي» فما فوق — وفق وثيقة
«مبادئ وضوابط أخلاقيات الذكاء الاصطناعي» (الإصدار 2.0).

## الأدوار والمسؤوليات (التعيينات المعتمدة — 2026-08-18)

- **مسؤول الذكاء الاصطناعي: علي الحازمي** — نقطة الاتصال مع سدايا، ومالك هذه
  الحزمة، ويقود مراجعتها، ويُسجَّل بهذه الصفة على منصة حوكمة البيانات الوطنية.
- **لجنة حوكمة الذكاء الاصطناعي** — تعتمد السياسة وتعديلاتها وتراجع سجل
  المخاطر دوريًا:
  - **عبدالرحمن الجوهري — رئيسًا**
  - **عيسى الحربي — عضوًا**
  - **عبدالسلام العنزي — عضوًا**
- **رئيس التحرير:** المسؤول التحريري النهائي عن كل ما يُنشر، ويتلقى تنبيهات
  الأعطال الحرجة للنماذج مباشرة.
- **مالكو الأنظمة:** كل نظام في بطاقات التعريف له مالك تقني مذكور فيها.

## المرجعية التقنية

كل بند في هذه الوثائق مسنود إلى الكود الفعلي في هذا المستودع (بوابة
`server/ai/gateway`، سجل `docs/systems/registry.json`، وتقرير الحصر والفجوات
المُعد في 2026-08-18). فجوات الأولوية الأولى الخمس أُغلقت في PR ‏#1449 قبل
إصدار هذه الحزمة.

## الإصدار والمراجعة

- تعديل أي وثيقة يمر بـPR يراجعه مسؤول الذكاء الاصطناعي.
- مراجعة دورية كاملة كل ستة أشهر أو عند إدخال نظام ذكاء اصطناعي جديد
  مواجه للجمهور — أيهما أسبق.
- عند التقديم لسدايا تُصدَّر الوثائق PDF وتُرفق عبر منصة حوكمة البيانات الوطنية.
