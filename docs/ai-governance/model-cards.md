# بطاقات تعريف الأنظمة الذكية

**الإصدار:** 1.0 — 2026-08-18 · تصنيف المخاطر وفق سلم سدايا الرباعي
(ضئيلة / محدودة / عالية / غير مقبولة). كل بطاقة تذكر مسار الكود المرجعي.

> اصطلاح: «البوابة الموحدة» = `server/ai/gateway` بسلاسل البدائل وقاطع الدارة
> وسجل `ai_usage_logs`. «الدستور التحريري» = `server/ai/sabqEditorialPrompt.ts`
> و`server/ai/prompts/constitution.ts`.

---

## 1. iFox — توليد المحتوى المجدول

| البند | البيان |
|---|---|
| الغرض | توليد مقالات لأقسام iFox الخمسة (`ai-*`) من أفكار مجدولة في التقويم التحريري |
| الكود | `server/jobs/ifoxContentGeneratorJob.ts` + `server/services/aiArticleGenerator.ts` |
| النموذج | Claude Sonnet (أساسي) ← GPT (بديل) + توليد صورة |
| المدخلات | فكرة الموضوع والكلمات المفتاحية من التقويم — لا بيانات قراء |
| الإشراف البشري | **مسودة افتراضيًا**؛ النشر الآلي يتطلب تفعيلًا صريحًا من اللوحة واجتياز بوابة الجودة (عتبة 90) — `resolvePublishDecision` |
| الوسم | المؤلف «سبق AI» + `aiGenerated: true` + عزل عن أقسام الموقع الرئيسية |
| السجلات | `ai_usage_logs` + سجل التقويم (محاولات، أخطاء) + فحوصات الجودة |
| المخاطر | توليد بلا مصدر خارجي ← خطر دقة؛ يُضبط بالمراجعة/بوابة الجودة |
| التصنيف | **عالية** (محتوى إخباري مولّد) — الضوابط تخفضها إلى مقبولة |

## 2. مولد المقالات والمهام المجدولة

| البند | البيان |
|---|---|
| الغرض | توليد مقالات (خبر/تحليل/تقرير) بثلاث لغات مع SEO ووسوم |
| الكود | `server/services/aiArticleGenerator.ts` + `server/services/aiTaskExecutor.ts` |
| النموذج | Claude Sonnet ← GPT، حرارة 0.4، يرفض المخرجات المبتورة وغير القابلة للتحليل |
| الإشراف البشري | مسودة افتراضيًا؛ `autoPublish` خيار لكل مهمة على حدة |
| الوسم | `aiGenerated: true` + مؤلف «سبق AI» |
| الضوابط | الدستور التحريري (لا اختلاق، لا معلومة غير مؤكدة) + فشل صريح بدل نشر نص خام |
| التصنيف | **عالية** — الضوابط تخفضها إلى مقبولة |

## 3. الرقابة الذكية على التعليقات

| البند | البيان |
|---|---|
| الغرض | تصنيف تعليقات القراء (آمن/مشتبه/سبام/ضار) وتقرير النشر أو الرفض أو المراجعة |
| الكود | `server/ai/commentModeration.ts` + `server/services/commentInsightsService.ts` |
| النموذج | GPT-4o-mini (+ بدائل من الفئة نفسها)، معايَر بأحكام مشرفين بشر few-shot |
| المدخلات | **نص التعليق** (بيانات شخصية) — مفصح عنه في سياسة الخصوصية |
| الإشراف البشري | «مشتبه» ← طابور بشري؛ المرفوض آليًا له **قناة اعتراض** تعيده وجوبًا لمراجعة بشرية (اعتراض واحد لكل تعليق)؛ خطأ النموذج ← معلّق للبشر (فشل نحو الإنسان) |
| الشفافية | إشعار الرفض يصرح أن القرار آلي + السبب + إرشاد الاعتراض؛ شارة «تمت الموافقة تلقائيًا» |
| السجلات | تحليل كامل على صف التعليق + تاريخ `comment_sentiments` + `flagged_comments_log` |
| التصنيف | **عالية** (قرارات تمس أفرادًا) — قناة الاعتراض والفشل نحو الإنسان ضابطان أساسيان |

## 4. محرك التوصيات والتخصيص

| البند | البيان |
|---|---|
| الغرض | تغذية «لك خصيصًا» والموجز اليومي من اهتمامات القارئ وسلوكه |
| الكود | `server/recommendation-engine.ts` |
| النموذج | إحصائي (لا LLM): سجل قراءة، اهتمامات، تشابه مستخدمين |
| المدخلات | سلوك القراءة داخل المنصة — يُخزن أولًا لدى سبق ولا يُرسل لمزود |
| الشفافية | سبب الترشيح معروض للقارئ («من اهتماماتك…») |
| فجوة معلومة | لا خيار انسحاب من التخصيص بعد — بند مفتوح في سجل المخاطر |
| التصنيف | **محدودة** |

## 5. تحليل المشاعر

| البند | البيان |
|---|---|
| الغرض | تصنيف مشاعر التعليقات (إيجابي/محايد/سلبي) كبيانات استرشادية للمشرفين |
| الكود | `server/sentiment-analyzer.ts` |

| التصنيف | **محدودة** |

## 6. محرر سبق — مساعد التحرير

| البند | البيان |
|---|---|
| الغرض | تحرير وتطوير النصوص داخل محرر المقالات وفق الدستور التحريري |
| الكود | `server/ai/prompts/constitution.ts` + واجهة `SabqEditorAssistant` |
| النموذج | Claude Sonnet عبر البوابة الموحدة |
| الإشراف البشري | **كامل** — المحرر يقبل أو يرفض كل مقترح؛ لا يكتب للنشر مباشرة |
| الضوابط | حراس الإخراج (كشف البتر + قفل الأرقام المصدرية ضد التحريف) |
| التصنيف | **ضئيلة** |

## 8. الاستوديو البصري — توليد الصور

| البند | البيان |
|---|---|
| الغرض | صور خبرية وأغلفة ومصغرات بسجل أنماط مركزي |
| الكود | `server/services/nanoBananaService.ts` + `imageStyleService.ts` + `autoImageGenerationService.ts` |
| النموذج | Gemini (نانو بانانا) مع بحث تأريض اختياري |
| الإشراف البشري | التوليد اليدوي: المحرر يختار وينشر (بصلاحية `articles.generate_images`)؛ التلقائي: حصص شهرية وقوائم استثناء |
| الوسم | `isAiGeneratedImage` + شارة «مولدة بالذكاء الاصطناعي» + إفصاح في النص البديل بثلاث لغات |
| السجلات | `ai_image_generations` يحفظ البرومبت الكامل والنموذج لكل صورة |
| فجوة معلومة | لا بصمة C2PA داخل الصورة، وبعض المسارات لا تضبط علم الوسم — سجل المخاطر |
| التصنيف | **محدودة** |

## 9. الصوتيات — الموجز الصوتي

| البند | البيان |
|---|---|
| الغرض | تخليق صوتي لملخصات المقالات ومواضيع مُقترب عند طلب القارئ |
| الكود | `server/routes.ts` (موجز المقالات) + `server/routes/topicSummaryAudio.ts` |
| النموذج | ElevenLabs ← Google TTS (بديل)، بكاش 24 ساعة وحارس حصص |
| الضوابط | النص يُبنى في الخادم من المحتوى المنشور حصرًا — لا نص حر من العميل |
| فجوة معلومة | لا إفصاح «صوت اصطناعي» عند المشغّل بعد — سجل المخاطر |
| التصنيف | **محدودة** |

## بقية الأنظمة (موجز)

| النظام | الغرض | الإشراف | التصنيف |
|---|---|---|---|
| وكيل الصحفي | بحث + مسودة خبر بخمس خطوات | مسودات فقط | محدودة |
| قصص البيانات | تحليل ملفات بيانات وقصة صحفية | تحويل يدوي لمسودة | محدودة |
| تحليل الصور والإنفوجرافيك | جودة/نص بديل/اقتراحات تصميم | اقتراحات فقط | ضئيلة |
| الرياضة اللحظية (لقطات، تقارير، تعريب) | تغطيات مولدة من بيانات المباريات الرسمية | دستور حياد خاص + «لا رقم بلا مصدر» | محدودة |
| الرادار وفجوات التغطية | رصد مصادر واقتراح تغطيات | مقترحات لمحررين | ضئيلة |
| وكيلا البريد وواتساب | استقبال مواد المراسلين ومعالجتها | مراجعة تحريرية | محدودة |
| استنساخ الأصوات | أداة إدارية (admin فقط) | يدوي بالكامل؛ يلزم توثيق الموافقة (سجل المخاطر) | عالية الحساسية |

> أي نظام جديد يُضاف هنا قبل تشغيله للجمهور، وفق القسم 5 من سياسة الاستخدام.
