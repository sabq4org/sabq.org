# قسم البطولات السعودية (Saudi Competitions Hub)

> **الحالة:** نموذج تفاعلي حي قيد التطوير — **مخفي** خلف feature flag، غير مدرج في أي قائمة.
> **الفرع:** `feat/saudi-league-hub` · **المسار:** `/saudi-league` · **آخر تحديث:** 2026-06-16
> **الهوية:** سبق المطوّرة (فاتح ونظيف، أخضر روشن/ذهبي، RTL).

قسم رياضي جديد يعرض بيانات حيّة لكل البطولات السعودية من **API-Football**، استعداداً
للموسم القادم. بُني معزولاً تماماً حتى لا يمسّ القسم الرياضي الحالي ولا قسم المونديال.

---

## التشغيل والمعاينة محليًا

```bash
# .env.local
SAUDI_LEAGUE_ENABLED=true      # بدونه ترد كل النقاط 404 (القسم مخفي)
APIFOOTBALL_KEY=<نفس مفتاح المونديال>   # خطة Mega — الدوري السعودي مغطّى بالكامل
# SAUDI_LEAGUE_SEASON لم يعد مستخدمًا — الموسم يُحلّ ديناميكيًا (انظر أدناه)

npm run dev      # المنفذ 5050 محليًا
# افتح: http://localhost:5050/saudi-league
```

> **الإخفاء بثلاث طبقات:** فرع مستقل + علم `SAUDI_LEAGUE_ENABLED` (افتراضيًا `false` في
> `.env.example`) + مسار غير مدرج في الـ nav. في الإنتاج يبقى كل شيء 404 حتى نرفع العلم.

## مزوّد البيانات

- **API:** API-Football v3 — `https://v3.football.api-sports.io`
- **المصادقة:** ترويسة `x-apisports-key` من `APIFOOTBALL_KEY` (نفس مفتاح المونديال).
- **الخطة:** Mega (150,000 طلب/يوم، تنتهي 2026-07-10 — أبقِ التجديد التلقائي).
- كل نقطة بيانات خلف كاش **SWR** (`server/memoryCache.ts`) فيخدم آلاف الزوار من طلب واحد.

## نقاط الـ API

> كلها عامة (بلا تسجيل دخول)، وترد 404 ما لم يُرفع العلم، و503 لو رُفع بلا مفتاح.

| الطريقة | الوصف |
|--------|------|
| `GET /api/saudi-league/competitions` | قائمة البطولات + أعلامها (لمبدّل البطولات) |
| `GET /api/saudi-league/:comp/fixtures` | كل مباريات البطولة (مرتّبة زمنيًا) |
| `GET /api/saudi-league/:comp/live` | المباريات المباشرة الآن (تحديث كل 15ث) |
| `GET /api/saudi-league/:comp/standings` | الترتيب (يرد `[]` للكؤوس) |
| `GET /api/saudi-league/:comp/scorers` | الهدّافون (أعلى 15؛ يرد `[]` لمن لا يدعمها) |
| `GET /api/saudi-league/match/:id` | تفاصيل مباراة: أحداث + إحصاءات (xG/استحواذ…) + تشكيلات. المعرّف عام فلا يحتاج تحديد البطولة |

## ما الذي بُني (مكتمل ومتحقَّق حيًّا)

- ✅ **مبدّل بطولات** أعلى الصفحة (6 بطولات).
- ✅ **مركز المباريات (Match Hub):** تبويبات مباشر/قادمة/نتائج + تحديث live.
- ✅ **جدول الترتيب** الكامل (فورمة آخر 5، حزم ألوان آسيوية/هبوط) — يظهر فقط لمن يدعمه.
- ✅ **الهدّافون** (صورة + أهداف + صناعة) — يظهر فقط لمن يدعمه.
- ✅ **نافذة تفاصيل المباراة بتابات:** «مجريات المباراة» (تايملاين عمودي) + «نبض الأرقام»
  (xG، الاستحواذ، التسديدات، التمريرات…) + «التشكيلات» (الخطة + المدرب + أساسي + بدلاء).
- ✅ **تكيّف التبويبات** حسب تغطية كل بطولة (الترتيب يختفي للكؤوس، الهدّافون للدرجة الثانية/السيدات).
- ✅ **تعريب الأدوار** للدوري (الجولة N) والكؤوس (دور الـ32، نصف النهائي…).

### سجل تحقّق حي (2026-06-16، موسم 2025/2026)
- دوري روشن: 306 مباراة، النصر متصدّر (86)، الهدّاف كينيونيس (33).
- مثال نبض أرقام (نيوم×الاتفاق): **xG 1.89-0.60**، الاستحواذ 62%-38%.
- الدرجة الأولى 309 مباراة، الثانية 483، كأس الملك 31، السوبر 3، السيدات 56.

## القيود المعروفة (نقاط التطوير القادمة)

1. **تعريب أسماء الأندية محدود:** القاموس (`SPL_TEAM_AR`) يغطّي أندية دوري روشن الـ18 فقط
   (وتكفي تلقائيًا لكأس الملك/السوبر لأنها نفس الأندية). **الدرجة الأولى/الثانية والسيدات
   تظهر بالإنجليزية** (Abha، Al Jeel، Al Nassr W). الحل: توسيع القاموس بمعرّفات تلك الأندية
   أو وصله بمترجم الـAI الموجود (`worldCupNameTranslator`).
2. **أسماء اللاعبين** لاتينية لغير النجوم المعروفين (نفس آلية المونديال).
3. **لا خريطة حرارية (heatmap)** — غير مدعومة في API-Football (تحتاج Opta/StatsBomb).
4. **الإحصاءات التفصيلية للمباراة** متاحة لدوري روشن فقط (`hasStats`)؛ بقية البطولات أحداث+تشكيلات بلا إحصاءات.

## خارطة الطريق (الأركان الأصلية من PRD المالك)

النموذج الحالي يغطّي **الركن 1 (Match Hub)** + الترتيب/الهدّافون/الأرقام. المتبقّي:

- **رادار الميركاتو (Transfer Tracker):** endpoint `/transfers` متاح (جرّبناه: 159 انتقالاً للهلال).
  ⚠️ مبالغ الصفقات غالبًا N/A في هذا المزود. سيرة اللاعب عبر `players/profiles`+`players/teams`+`trophies`+`injuries`.
- **غرفة الأخبار (The Locker Room):** أخبار تحريرية — إعادة استخدام محرّك أخبار المونديال
  (`worldCupNewsGenerator` + `worldCupNewsJob`) + تصنيف رياضي. هنا يدخل «التصنيف» المخفي.
- **منطقة الجمهور (Fan Zone):** تصويت/توقّعات — قاعدة جاهزة في `wcPredictionsService`؛
  و`/predictions` يعطي توقّع AI للنتيجة. (الفويس شات/الأهازيج ميزة real-time ضخمة منفصلة — مؤجّلة.)

### تحسينات تقنية مقترحة
- توسيع `SPL_TEAM_AR` لأندية الدرجات الأدنى والسيدات (أو وصل مترجم AI).
- عرض التشكيلة على **أرضية ملعب** (grid) بدل قائمة (المزود يرسل `grid` لكل لاعب).
- **AI يكتب خبرًا فور الحدث** (هدف/نهاية مباراة) بناءً على أحداث المباراة — امتداد لمحرّك أخبار المونديال.
- **Push notifications للأهداف** (البنية جاهزة: `pushWorker` + `notificationBus`).
- قبل أي ظهور إنتاجي: إضافة `/saudi-league` إلى `isNoindexPath()` حتى لا يُفهرس وهو قيد التطوير.
- نقل المنطق المشترك مع المونديال (apiGet/الحالات) إلى helper موحّد إن توسّع القسمان.

## ملاحظات نشر

- معزول تمامًا: لا يلمس `worldCupService` ولا القسم الرياضي الحالي (يستورد ثوابت تعريب
  للقراءة فقط من `worldCupNames`).
- الراوتر لا يستورد `db` (ملتزم بـ ADR-001). الخدمة تستدعي API خارجيًا فقط.
- لتفعيله إنتاجيًا لاحقًا: ضبط `SAUDI_LEAGUE_ENABLED=true` على Railway + ربط المسار في الـ nav.
