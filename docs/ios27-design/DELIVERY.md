## التحقق المحلي

- نجح بناء Debug للمحاكي وRelease للجهاز دون توقيع، باستخدام Xcode 27 RC.
- نجحت 99 حالة وظيفية واثنتان للتنقّل. أُعيد اختبار التنقّل بعد إصلاح حساب iPad ونجح.
- معاينات iPhone للمحفوظات والحساب ونافذة الدخول والحساب في الوضع الداكن مع النص الكبير؛ معاينة iPad أكدت إزالة عمود القراءة الفارغ من الحساب.
- الحد الأدنى iOS 17.0 محفوظ. رقم الإصدار 10.3.2 في مساحة Xcode إعداد محلي سابق للمستخدم؛ لم يُضم تغيير `project.pbxproj` إلى هذه الدفعة.
- لا تغيير في APIs أو قاعدة البيانات أو الويب أو VARA. لا اعتماديات جديدة.

## حدود الاعتماد

نجاح البناء والفحوص لا يمثل رفعاً إلى TestFlight أو App Store أو اعتماداً من Apple. الأرشيف الموقّع، الجهاز الفعلي، iOS 17 الفعلي، APNs، والفحص الشامل للشاشات المحمية بحساب وVoiceOver تبقى ضمن اعتماد الإصدار.

نتائج GitHub وحالة الدمج النهائية موثقتان في طلب الدمج المرتبط بالمهمة. لا يتطلب تعديل iOS وحده نشر API على Railway؛ أي بناء ويب تلقائي يُتحقق منه على commit الدمج بصورة مستقلة.
