# تدقيق كتالوج الأنظمة — 2026-07-17

## ماذا رُاجع؟
- كل مدخل في `registry.json` (18 نظاماً)
- كل `featureKey` في `server/ai/gateway/defaults.ts` (41 مفتاحاً)
- مفاتيح runtime إضافية تُمرَّر كـ `feature:` في الكود (رياضة + رأي الكاتب)

## قواعد الملكية
1. كل `featureKey` يملكه **نظام واحد فقط** (لا تكرار → لا تضخيم للأرقام).
2. الأنظمة بلا AI تبقى `aiFeatureKeys: []` بصراحة.
3. الاستهلاك غير المهاجر عبر `ai-manager` يُنسب لـ `ai-hub` عبر `legacy-ai-manager`.
4. توليد SEO بالذكاء تحت `editorial`؛ حقن الميتا/SSR تحت `seo-ssr` بدون مفاتيح AI.

## إصلاحات هذا التدقيق
- نقل `prompt-studio` / `legacy-ai-manager` / `entity-extraction` من editorial → ai-hub
- إضافة مفاتيح ناقصة: sentiment، agents، ifox tasks، embeddings، sports-intel، opinion-writer
- توسيع `pathGlobs` للتحرير/الرياضة/التعليقات/ai-hub/ifox

## ملاحظة تشغيل
