# مواصفات استكمال منصة كأس آسيا 2027

> الحالة: معتمدة للتنفيذ · التاريخ: 2026-07-12 · Umbrella: يُربط بعد إنشاء Issue

## الهدف

إكمال منصة كأس آسيا 2027 كمنتج موحّد بين تطبيق iOS والويب، مع مصدر بيانات واحد، حساب وتوقعات ومتابعات مشتركة، مركز مباراة حي، صفحات المنتخبات واللاعبين، دعم اللغات، الإشعارات والروابط العميقة، ثم مطابقة Android مع iOS وفق `AGENTS.md`.

## نطاق المنصات وترتيب التنفيذ

1. Backend والعقود المشتركة.
2. iOS (`asian-cup app ios/AsianCup.xcodeproj`) بوصفه المرجع البصري.
3. Android native بمطابقة iOS 1:1.
4. Web بتصميمه المستقل مع parity وظيفي.

## Spec UI

### iOS والمرجع البصري لأندرويد

- تبويبات: الرئيسية، المباريات، التوقعات، المجموعات، المزيد.
- مركز مباراة: الملخص، المباشر، الأحداث، الإحصاءات، التشكيلات، تقييمات اللاعبين، H2H، التوقعات، المتابعة والتنبيهات.
- ملف منتخب: الهوية، المجموعة، الفورمة، القائمة والمدرب، طريق التأهل، الإصابات، المباريات والأخبار.
- ملف لاعب: الهوية، إحصاءات البطولة، المسيرة، الإصابات، الانتقالات والبطولات.
- الهدافون، الشجرة الإقصائية، الملاعب، إعدادات اللغة، الحساب والتنبيهات.
- حالات كاملة للتحميل، الفراغ، الخطأ، انقطاع الشبكة وعدم توفر بيانة من مزوّد.
- دعم VoiceOver وDynamic Type وRTL/LTR وiPhone/iPad وiOS 17+.
- تسجيل الدخول عبر Apple، حفظ الجلسة في Keychain، ومشاركة الروابط العميقة.
- APNs وLive Activities للمباريات المتابَعة.

### Android

- نفس الشاشات والتوزيع والألوان والمسافات والسلوك في `android-native/` باستخدام Compose وAPI 26+.

## Spec API

### المصادر

- API-Football: الجدول، المجموعات، الترتيب، المنتخبات، اللاعبين، الهدافين والتشكيلات.
- TheSports: النتيجة والأحداث والإحصاءات اللحظية، MQTT أولاً ثم REST.
- SportMonks: xG والضغط والزخم والطقس والغيابات والتعليق عند توفر تغطية كأس آسيا.
- خدمات سبق: الحسابات، التوقعات، المتابعات، التنبيهات والأخبار.

### العقود العامة

- تبقى قراءات الويب العامة تحت `/api/asian-cup/*`.
- توفر مرايا القراءة العامة للموبايل تحت `/api/v1/asian-cup/*` حيث يلزم توحيد العميل.
- عمليات الموبايل المحمية تستخدم Bearer و`verifyMemberSession` فقط.
- عمليات الويب المحمية تستخدم Passport فقط.
- كل كيان ديناميكي يعيد معرّفاً ثابتاً، رمز حالة قانونياً، `nameEn`، والاسم المحلي عند توفره.
- كل قسم إثراء يعيد `available`, `source`, `updatedAt` ولا يعطّل الحمولة الأساسية عند فشل مزوّد.

### المسارات المحمية للموبايل

- `GET /api/v1/asian-cup/predictions/today`
- `POST /api/v1/asian-cup/predictions`
- `GET /api/v1/asian-cup/predictions/mine`
- `GET /api/v1/asian-cup/predictions/leaderboard`
- `GET /api/v1/asian-cup/predictions/match/:fixtureId`
- استخدام `/api/v1/sports/follows` و`/api/v1/sports/alert-prefs` للمتابعات والتنبيهات المشتركة.

### الكاش والتشغيل

- مباشر: 5–15 ثانية، وقبل البداية: 30–60 ثانية، ومرجعي: 5 دقائق–24 ساعة.
- لا كاش عام لأي رد يحمل بيانات مستخدم.
- تسلسل fallback: TheSports → SportMonks → API-Football للنتيجة الحية فقط.
- مراقبة زمن كل مزوّد، معدل fallback، استهلاك الحصة وأخطاء المطابقة.

## Spec Schema

- الأولوية لإعادة استخدام جداول التوقعات والمتابعات وتفضيلات التنبيه الحالية.
- أي تغيير في `shared/schema.ts` يكون additive only مع nullable/default.
- لا حذف أو تعديل migration قديم.
- إن احتاجت روابط المزودين تخزيناً دائماً، تضاف حقول/جدول ربط مستقل دون تغيير المعرفات الحالية.

## Spec Web

- الإبقاء على `/asian-cup` كبوابة رئيسية.
- إضافة صفحات مستقلة:
  - `/asian-cup/match/:id`
  - `/asian-cup/team/:id`
  - `/asian-cup/player/:id`
  - `/asian-cup/scorers`
  - `/asian-cup/bracket`
  - `/asian-cup/venues`
- حساب وتوقعات ومتابعات مشتركة مع التطبيق.
- SEO وcanonical وOpen Graph وJSON-LD وhreflang للمسارات العامة.
- إضافة المسارات إلى Edge Meta وCloudflare middleware.
- Universal Links تفتح الشاشة المطابقة في التطبيق، مع الويب كـfallback.

## اللغات

- دعم السجل الحالي: `ar`, `en`, `fa`, `ur`, `ja`, `ko`, `zh-Hans`, `vi`, `th`, `id`, `ms`, `hi`, `uz`, `tg`, `ky`, `bn`.
- لا تظهر لغة قابلة للاختيار قبل اكتمال 100% من مفاتيحها.
- CI يفشل عند اختلاف المفاتيح أو placeholders أو وجود قيم فارغة.
- أسماء المنتخبات تترجم لكل اللغات؛ أسماء اللاعبين تستخدم الاسم الأصلي القانوني مع تعريب عربي موثوق.
- يدعم الويب اللغات المتفق عليها بمسارات قابلة للفهرسة وhreflang.

## معايير القبول

- بناء TypeScript وiOS وAndroid ناجح، واختبارات E2E والعقود ناجحة.
- توقع محفوظ من iOS يظهر في الويب للحساب نفسه والعكس.
- Universal Link يفتح مباراة/منتخب/لاعب في الشاشة الصحيحة.
- Replay لمباراة يمر قبل البداية → مباشر → استراحة → نهاية دون نتيجة متعارضة.
- فشل أي مزود لا يسقط الصفحة أو التطبيق.
- صفر مفتاح ترجمة ناقص وصفر fallback غير مقصود للغات المعلنة.
- APNs وLive Activity مجرّبان على جهاز حقيقي.
- Android يطابق iOS 1:1 قبل إغلاق Umbrella، أو يسجل بتأجيل رسمي مع سبب وإصدار محدد.
