# مرجع واجهة صحيفة سبق

تاريخ المراجعة: 2026-09-11. النطاق: واجهات القراءة العامة على الويب. لا يغيّر هذا المرجع تصميم لوحة التحرير أو التطبيقات الأصلية أو الهوية الخاصة بالحملات.

## مصدر التنسيق

- `client/src/styles/public-design.css`: ألوان الأسطح والنصوص والخطوط والمسافات وحالات التركيز. الصفحة بيضاء، والسطح الثانوي الموحد `#F4F8FB`، والبطاقات بيضاء؛ لكل قيمة مقابل داكن. الاستخدام opt-in عبر `public-page` أو `public-theme`؛ لا تستبدل متغيرات shadcn العامة.
- `NewsArticleCard`: الخبر العادي بثلاث كثافات: شبكة، قائمة، صف مختصر. تستخدمه الرئيسية والأخبار والتصنيفات والوسوم وأرشيف التصنيف والتوصيات والملفات الشخصية والنسخ الإنجليزية والأردية.
- `ContentLabel` و`ArticleMedia` و`ArticleMeta` و`ArticleActions`: مصدر واحد لليبل والصورة والتوقيت والحفظ والمشاركة. تُحل هوية التصنيف من كتالوج `/api/categories` حتى لا يختلف اللون بسبب نقص بيانات أحد الـfeeds.
- `OpinionCard`: بطاقة الرأي في الرئيسية والأرشيف والقائمة الجانبية. عنوان المقال يسبق بيانات الكاتب في القائمة الجانبية.
- `ArticleSidebarHeading`: رأس موحد للوحدات الجانبية في تفاصيل الأخبار والرأي.
- `article-detail.css`: ترتيب ومقاسات تفاصيل الخبر ومقال الرأي. الليبلات، العنوان، العنوان الفرعي إن وجد، الكاتب والتوقيت، الصورة إن وجدت، الموجز، النص والكلمات المفتاحية، ثم المشاركة والإعجاب والحفظ والتركيز والتعليقات. تحفظ الوحدات الخاصة بالمقال مثل تقييمه وسيرة كاتبه.
- `PublicationLayout`: مكونات الصفحة والرأس والحالة الفارغة المشتركة للصفحات الجديدة. الصفحات القائمة تستخدم أيضًا نفس أصناف CSS مباشرة.

## عقود يجب الحفاظ عليها

1. اختلاف كثافة البطاقة مقصود حسب المساحة؛ اختلاف لون الليبل أو التوقيت أو أحجام النص الأساسية لنفس الكثافة غير مقصود.
2. روابط الخبر تحافظ على اللغة `/article` أو `/en/article` أو `/ur/article`، وكذلك روابط الإنفوجرافيك. أرشيف SEO يمرر الرابط القانوني `href` صراحة؛ معرفه المحلي مفتاح عرض فقط ولا يستخدم في طلبات الكتابة.
3. الحفظ العربي والإنجليزي POST للتبديل؛ الأردي POST للإضافة وDELETE للإزالة على المسار المفرد `/api/ur/article/:id/bookmark`. لا يتغير شكل الحفظ إلى نجاح قبل استجابة الخادم. أخطاء الطلب تبقي الحالة السابقة.
4. callback الحفظ أو المشاركة، عند توفيره، يملك تنفيذ العملية. لا تُرسل عملية ثانية من المكوّن. الحالة القادمة من الصفحة تتزامن مع البطاقة.
5. التوقيت المطلق ميلادي بأرقام لاتينية حسب الرياض. النسبي بلغة الواجهة. التاريخ غير الصالح لا يظهر كـInvalid Date في البطاقة.
6. صورة الخبر تحافظ على صورة العرض ونقطة التركيز وبيان توليد الصورة؛ لا تُحذف مؤشرات الفيديو أو الإنفوجرافيك.
7. بانر دوري روشن يحتفظ بتصميمه الداخلي، والغلاف الخارجي شفاف.
8. نماذج الدخول والتسجيل والتحقق تستخدم أصنافًا محصورة في الواجهة العامة؛ لا يتغير عقد المصادقة.

## التحقق قبل تعديل المكونات

مع تشغيل Vite محليًا، افتح `/__preview/public-design`. هذا المسار متاح في التطوير فقط ويستخدم بيانات تجريبية ومكونات التطبيق الحقيقية. لا تختبر الكتابة بحساب إنتاج لأغراض التحقق.

```sh
npm run check
npm run build:client
npx vitest run tests/unit/publicArticleTime.test.ts
PW_PUBLIC_DESIGN=1 PW_BASE_URL=http://127.0.0.1:5184 npx playwright test e2e/public-design.spec.ts
```

عنوان المعاينة مثال؛ استبدله بعنوان خادم التطوير المحلي. اختبارات Playwright تعترض جميع طلبات API ببيانات اختبار، وترفض التشغيل خارج localhost. تفحص 320 و390 و768 و1024 و1440 في المظهرين، عقود الحفظ والفشل وCSRF والتوجيه للدخول، والروابط والمشاركة واللغات. افحص بصريًا أيضًا الصور الحقيقية والعنوان الطويل والرئيسية والوسم والتصنيف وتفاصيل الخبر والرأي ووضع التركيز.

## نتيجة التحقق لهذه الدفعة

- 7 اختبارات Playwright و4 اختبارات توقيت نجحت.
- 30 معاينة للصفحات الأساسية على 390 و1440 وفي المظهرين: دون تجاوز أفقي أو أخطاء JavaScript مرصودة.
- 4 تجارب فتح وضع التركيز في الخبر والرأي على الجوال والكمبيوتر: تغيير حجم الخط والمظهر، إنهاء الجلسة، إغلاق ملخصها، واستعادة التركيز إلى زر الدخول.
- فُحصت صفحات النماذج والغلاف والصفحات الثانوية بواسطة الوكلاء، مع مراجعة مستقلة للكود ومراجعة نهائية مجمعة.
- نجاح هذه الفحوص لا يمثل نشرًا أو اختبارًا شاملًا لكل صفحات الصحيفة أو لكل حساب مسجل. لم تُجرَ كتابات على بيانات الإنتاج؛ اختبارات التفاعل تستخدم بدائل API محلية.


### تصحيح القوائم الجانبية وبيانات الكاتب — 2026-09-11

عُزلت حشوة CSS القديمة عن البطاقة المشتركة: كانت قاعدة `article-sidebar-related a > div` تضيف 18 بكسل داخل حاوية الصورة فتجعل صورة بارتفاع 44 داخل إطار 80. أزيلت أيضًا حشوة نص البطاقة المختصرة ومساحة الليبل الفارغ. يقيس اختبار Playwright موضع بداية العنوان وحدود الصورة مقارنة بإطارها داخل سياق القائمة الجانبية نفسه، على الجوال والكمبيوتر والمظهرين. مصدر المسمى تحت كاتب الرأي هو ملف المراسل عند توفره، والبديل الوصفي «كاتب رأي». شريط تفاعل الرأي يستخدم تجميع وفئات وأحجام شريط الخبر؛ تمت مقارنة الأنماط المحسوبة للأزرار في الصفحتين.


### موجز الخبر والرأي

`components/public/ArticleSummary.tsx` هو واجهة الموجز في الصفحتين. النص المخزن يُعرض كاملًا عند التوسيع دون تحويل إلى ثلاث نقاط أو إضافة نسخة مكررة. لا يتغير عقد الاستماع أو جلب الموجز. زر «عرض المزيد / طيّ» يعتمد على تجاوز النص ثلاثة أسطر فعلية ويُعاد قياسه عند تغير العرض والخط، وتُعاد حالة الطي عند الانتقال لمقال آخر. التحقق يغطي المقال والخبر الواردين في ملاحظات المستخدم على Chromium وWebKit بعرضي 390 و1440، ونصًا اختباريًا من خمس فقرات مع أرقام وموجزًا قصيرًا لا يحتاج زرًا.
