# إصلاح رفع صور الألبوم لمدير المحتوى

تاريخ التوثيق: 2026-05-19

## ملخص المشكلة

كان مستخدمو دور `content_manager` (مدير محتوى) يواجهون فشل رفع الصور عند استخدام نافذة رفع صور متعددة داخل محرر المقال، خصوصا عند إضافة صور ألبوم. تظهر الواجهة أن الملف وصل إلى 100% ثم تعرض رسالة:

```text
Unauthorized
```

## الأثر

- لا يستطيع مدير المحتوى إرفاق صور الألبوم بالمقال.
- تجربة الرفع تبدو وكأنها نجحت جزئيا لأن شريط التقدم يصل إلى 100% قبل ظهور الخطأ.
- المشكلة تؤثر على مسار رفع الصور المتعددة المستخدم في الألبومات، وقد تظهر في البيئات التي تفصل الواجهة عن الخادم إذا لم يستخدم طلب الرفع عنوان الـ API الموحد.

## السبب الجذري

كان هناك سببان محتملان يتقاطعان في نفس المسار:

1. دور `content_manager` كان يملك صلاحية عرض مكتبة الوسائط (`media_library.view`) لكنه لا يملك صلاحيات رفع الوسائط المطلوبة مثل `media.upload` و`media_library.upload`.
2. مكون رفع صور الألبوم كان يرسل الطلب مباشرة إلى `/api/media/upload` عبر `XMLHttpRequest`، بدل استخدام دالة `apiUrl()` المشتركة. هذا قد يرسل الطلب إلى أصل غير صحيح في بيئات النشر ذات الواجهة والخادم المنفصلين، مما يجعل الجلسة لا تصل للخادم ويرجع الرد `Unauthorized`.

## الحل المطبق

- إضافة `content_manager` إلى تعريفات RBAC المشتركة.
- منح مدير المحتوى صلاحيات:
  - `media.view`
  - `media.upload`
  - `media_library.view`
  - `media_library.upload`
- تحديث ملف تصدير RBAC ليعكس صلاحيات الرفع.
- تحديث seed الخاص بـ RBAC حتى قواعد البيانات الجديدة تحصل على نفس الصلاحيات.
- إضافة migration يعالج قواعد البيانات الحالية بدون إعادة زرع كل الأدوار.
- تحديث مكون رفع صور الألبوم ليستخدم `apiUrl('/api/media/upload')` وينتظر `ensureCsrfToken()` قبل الإرسال.

## تفعيل الإصلاح في البيئة

بعد نشر الكود، يجب تشغيل migration التالي على قاعدة البيانات:

```sql
migrations/0005_content_manager_media_upload.sql
```

بعدها يحتاج مستخدمو مدير المحتوى إلى تحديث الصفحة أو تسجيل الدخول مجددا إذا بقيت الصلاحيات القديمة في الكاش لفترة قصيرة.

## التحقق

تم تشغيل فحص TypeScript العام. الفحص ما زال يفشل بسبب أخطاء موجودة مسبقا خارج نطاق هذا الإصلاح، لكن لا توجد أخطاء جديدة مرتبطة بالملفات المعدلة أو بدور `content_manager` أو مكون `ImageUploadDialog`.
