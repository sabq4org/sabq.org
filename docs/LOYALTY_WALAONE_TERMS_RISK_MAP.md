# خريطة مخاطر: شروط ولاء ون → حماية سبق

**التاريخ:** 2026-07-17  
**الحالة:** مسودة تشغيلية/قانونية — للمراجعة مع المستشار القانوني  
**صفحة الشروط الخاصة بسبق:** `/loyalty-terms` → `client/src/pages/LoyaltyTermsPage.tsx`  
**مرجع ولاء ون:** الشروط المنشورة على [walaone.com](https://www.walaone.com) (نص زُوِّد للفريق في 2026-07-17)

---

## المبدأ الحاكم

```
محفظة سبق (اكتساب + رصيد داخلي)
        │
        │  استبدال / شحن رسمي فقط
        ▼
ولاء ون (استخدام + انتهاء صلاحية + شركاء)
```

- **قبل الاستبدال:** سبق تملك قواعد الاكتساب والأسقف والإلغاء داخل منصاتها.
- **بعد الاستبدال:** شروط ولاء ون تسود على النقاط المنتقلة؛ سبق تعزل مسؤوليتها عن تأخير ولاء ون وتعديل عروضها وانتهاء صلاحيتها.

بدون هذا الفصل، أي تغيير من ولاء ون (انتهاء 12 شهرًا، إلغاء عروض، عدم استرجاع) قد يُحمَّل على سبق أمام القارئ.

## جدول البنود: ولاء ون → بند سبق المقابل

| بند ولاء ون (ملخّص) | الخطر على سبق إن لم نُغطِّه | الحماية في `/loyalty-terms` |
|---------------------|----------------------------|-----------------------------|
| القبول بالانضمام = قبول قوانين البرنامج + شروط الموقع | عضو يطالب بأن «سبق قالت غير كذا» | §01 قبول صريح + تكميل لشروط المنصة |
| تأخير تحديث النقاط بسبب عجز النظام | شكاوى دعم / اتهام بخصم نقاط | §03 التأخير ممكن + مسؤولية التحقق |
| اكتساب عبر شركاء / شحن محفظة / حملات | خلط بين «نقاط سبق» و«شحن مدفوع ولاء ون» | §02 طبقتان منفصلتان بوضوح |
| استبدال فقط بما تسمح به ولاء ون | توقّع استبدال نقدي أو خارج التطبيق | §02 + §04 لا نقد لدى سبق؛ بعد النقل تسري ولاء ون |
| **عدم استرجاع** بعد شحن المحفظة | طلب إعادة نقاط بعد الاستبدال | §04 العملية نهائية من جهة سبق بعد استبدال ناجح |
| النقاط داخل التطبيق فقط؛ لا بيع/تداول/تحويل | سوق سوداء أو تحويل بين أعضاء سبق | §05 حظر البيع والتحويل في سبق + الإشارة لقيود ولاء ون |
| انتهاء بعد **12 شهرًا**؛ إغلاق الحساب يلغي النقاط | عضو يلوم سبق بعد انتهاء رصيد ولاء ون | §06 فصل صلاحية محفظة سبق عن صلاحية ولاء ون + إخلاء |
| حملات/هدايا/كاش باك: انتهاء **14 يومًا** + FIFO | توقّع صلاحية طويلة لمكافآت ترويجية | §06 ذكر صريح لـ 14 يومًا و FIFO كما تنشره ولاء ون |
| إلغاء نقاط عند احتيال/استغلال | زراعة قراءة / حسابات وهمية | §07 إساءة الاستخدام + خصم/إلغاء رصيد سبق |
| مطالبة بنقاط ناقصة خلال **15 يومًا** + إثبات | مطالبات قديمة بلا أثر | §08 مهلة 15 يومًا لمطالبات سبق؛ نزاعات ولاء ون → ولاء ون |
| ولاء ون تعدّل/توقف البرنامج والعروض دون إعلان أحيانًا | سبق تُسأل عن اختفاء عرض شريك | §09 تعديل البرنامج والشركاء + إخلاء عن تغييرات ولاء ون |
| حدود مسؤولية واسعة لولاء ون | دعاوى أضرار غير مباشرة ضد سبق | §10 حدود مسؤولية سبق + سقف إعادة قيد نقاط فقط |
| العضو مسؤول عن حسابه وكلمة المرور | عمليات استبدال من حساب مخترق | §10 مسؤولية الحساب |
| تغيير الشركاء والمنافذ من آن لآخر | اعتماد تسويقي على شريك محدد | §09 إنهاء/تعليق التعاون مع ولاء ون ممكن |

## بنود «خاصة فينا» ليست نسخة من ولاء ون

هذه ما يجب أن تبقى هوية سبق القانونية — لا تُستبدل بشروط الشريك:

1. **جدول اكتساب الصحيفة** (قراءة، دخول، تفاعل) ملك سبق وحدها.
2. **صفحات المعاينة غير ملزمة** حتى الاعتماد الرسمي (§03) — يحمي من `/loyalty-preview`.
3. **سقف التعويض = إعادة قيد نقاط سبق** لا نقد (§10).
4. **مهلة مطالبات موحّدة 15 يومًا** متوائمة مع ولاء ون لتسهيل الدعم، لكن القناة مختلفة (سبق vs ولاء ون).
5. **القانون السعودي + مسار دعم سبق** للنزاعات المتعلقة بمحفظة سبق (§12).

## قائمة تشغيل قبل الإطلاق مع ولاء ون

- [ ] مراجعة `/loyalty-terms` من المستشار القانوني واعتمادها (إزالة شارة «مسودة»).
- [ ] ربط قبول الشروط عند أول دخول لمحفظة الولاء أو قبل أول استبدال (checkbox / سجل قبول).
- [ ] في UI الاستبدال: جملة واضحة «بعد التأكيد تسري شروط ولاء ون ولا يمكن التراجع».
- [ ] عرض رابط ولاء ون + رابط `/loyalty-terms` في شاشة المحفظة.
- [ ] سياسة صلاحية داخل محفظة سبق (إن رغبتم بمدة قبل التحويل) — قرار منتج منفصل عن 12 شهر ولاء ون.
- [ ] مسار دعم: تذكرة «نقاط سبق» vs تحويل العضو لولاء ون إذا كان الرصيد هناك.
- [ ] عدم وعد تسويقي يتعارض مع: لا نقد، لا تحويل للغير، انتهاء صلاحية، إمكانية تعديل البرنامج.
