# قوائم API المفهرسة رغم robots — 7 سبتمبر 2026

Issue #1535. Search Console عرض8 روابط مفهرسة رغم حظر robots؛ ثلاثة منها قوائم JSON: `/api/articles`، `/api/articles?page=1&limit=10`، `/api/v2/articles`. الخمسة الباقية وسائط أرشيفية، وليست ضمن هذا الإصلاح.

الإصلاح يضيف `X-Robots-Tag: noindex, nofollow` إلى GET/HEAD لقائمتي API فقط، ويسمح لGoogle بقراءة المسارين التامين ومعاملاتهما. تبقى تفاصيل المقالات وواجهات المصادقة وبقية/API محظورة. تطبق الترويسة وقواعد robots من إصدار الخادم نفسه، دون تغيير محتوى JSON أو الكاش أو الصلاحيات.

اختبارات HTTP محلية حقيقية: الترويسة مع المسار التام والمعاملات والشرطة الأخيرة؛ JSON محفوظ؛ المصادقة تبقى401؛ لا ترويسة على ملفات الوسائط وتفاصيل الأخبار أو المسارات المشابهة. فحص قواعد السماح يثبت عدم فتح المسارات الأبناء. الاختبارات الستة وبناء الخادم وفحص TypeScript وESLint نجحت محلياً (تحذيرات lint قديمة، دون أخطاء).

بعد النشر: فحص الترويسة والـrobots على الإنتاج، ثم الاختبار المباشر لأمثلة GSC. Google قد يحتفظ بنسخة robots حتى24 ساعة أو أكثر عند تعذر التحديث؛ إسقاط الروابط يحتاج إعادة زحف. لا تبدأ validation باعتباره حل جميع8 روابط قبل معالجة أمثلة الوسائط على حدة.

المراجع: [noindex للموارد غيرHTML](https://developers.google.com/search/docs/crawling-indexing/block-indexing)، [مطابقة قواعد robots](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec).
