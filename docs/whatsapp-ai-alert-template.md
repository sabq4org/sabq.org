# تنبيهات الذكاء الاصطناعي عبر واتساب — قالب معتمد (يحل مشكلة «queued لكن لم تصل»)

## الخلفية

تنبيهات «مركز التحكم بالذكاء الاصطناعي» (فشل / نفاد رصيد / تدهور / تعافٍ) تصل واتساب رئيس
التحرير عبر Twilio. المنطق يعمل بالكامل: عند تغيّر حالة قاطع الدائرة يُطلق
`handleAiProviderStatusChange` رسالة واتساب. لكن رُصد أن الرسائل **تُقبل من Twilio بحالة
`queued` ولا تصل الجهاز**.

**السبب:** رسائل واتساب **النصية الحرة** (free-form) لا تُسلَّم إلا **داخل نافذة 24 ساعة**
تفتحها رسالة واردة من المستلم إلى رقم الأعمال. خارج هذه النافذة يرفضها واتساب بالخطأ
`63016` («User has not responded in 24 hours — template required»). الرفض **غير متزامن**:
الاستدعاء المتزامن يرجّع `queued` بنجاح، ثم يصل الفشل الحقيقي عبر status-callback. لذلك كان
اللوق يطبع `sent 3/3` بينما لم يصل شيء.

**الحل الوحيد للتسليم خارج النافذة = قالب واتساب معتمد (Approved Template).** لا يمكن حل هذا
بالكود وحده؛ يلزم تسجيل قالب في Twilio/Meta واحدة.

---

## الحل الفوري (بدون قالب — ترقيع)

يرسل كل مستلم أي رسالة واتساب إلى رقم الأعمال (مثال: `+1 270 479 7404`) — هذا يفتح نافذة
24 ساعة، فتصل التنبيهات النصية الحرة خلالها. لكنها **تُغلق كل 24 ساعة** فهي غير موثوقة.

---

## الحل الدائم (قالب معتمد)

### 1) أنشئ قالب Content في Twilio

Twilio Console → **Messaging → Content Template Builder → Create new**:

- **Type:** `Text`
- **Category:** `Utility` (تنبيه تشغيلي — أسرع اعتمادًا من Marketing)
- **Language:** `Arabic (ar)`
- **Friendly name:** `sabq_ai_critical_alert`
- **Body:**

```
تنبيه حرج — منظومة الذكاء الاصطناعي
{{1}}

المزوّد: {{2}}
النموذج: {{3}}
الحالة: {{4}}
التفاصيل: {{5}}

🕒 {{6}}
🔗 لوحة المراقبة: sabq.org/dashboard/ai-hub
```

- **Sample values** (لتسريع المراجعة):
  - `{{1}}` = `🔴 نفاد رصيد المزوّد`
  - `{{2}}` = `Anthropic`
  - `{{3}}` = `claude-sonnet-4-6`
  - `{{4}}` = `صحي ← نفد الرصيد`
  - `{{5}}` = `QUOTA_EXCEEDED — insufficient credit`
  - `{{6}}` = `5 يوليو 2026، 11:14`

> ملاحظات القبول: لا تبدأ ولا تنتهِ الرسالة بمتغيّر، ولا تجعل متغيّرين متلاصقين — القالب أعلاه
> يلتزم بذلك (سطر ثابت في البداية ورابط ثابت في النهاية). المتغيّرات تُملأ من الكود بقيم
> **سطر واحد** فقط (يجمع الكود المسافات ويقصّ الأسطر تلقائيًا).

بعد الاعتماد انسخ **Content SID** (يبدأ بـ `HX...`).

### 2) اضبط متغيّر البيئة على Railway

```
AI_ALERT_WHATSAPP_CONTENT_SID=HXxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

بمجرد ضبطه: تُرسَل التنبيهات كقالب وتصل **داخل النافذة وخارجها**. إذا لم يُضبط، يعود الكود
تلقائيًا للنص الحر (سلوك اليوم — يصل داخل النافذة فقط).

### 3) خريطة المتغيّرات (مرجع)

يبنيها `buildTemplateVariables` في [`server/services/aiCriticalAlerts.ts`](../server/services/aiCriticalAlerts.ts):

| المتغيّر | المصدر | مثال |
|---|---|---|
| `{{1}}` | إيموجي + عنوان التنبيه | `🔴 نفاد رصيد المزوّد` |
| `{{2}}` | اسم المزوّد | `Anthropic` |
| `{{3}}` | مُعرّف النموذج | `claude-sonnet-4-6` |
| `{{4}}` | تحوّل الحالة | `صحي ← نفد الرصيد` |
| `{{5}}` | رمز الخطأ + تفصيل مقتضب | `QUOTA_EXCEEDED — …` |
| `{{6}}` | الوقت (توقيت الرياض) | `5 يوليو 2026، 11:14` |

## التحقّق من التسليم الحقيقي (لا تثق بـ`queued`)

كل تنبيه يُرسل الآن مع `statusCallback` إلى `/api/whatsapp/status-callback`. راقب لوق Railway:

- `[WhatsApp Status] ✅ Message … Status: delivered` → وصلت فعلًا.
- `[WhatsApp Status] ❌ DELIVERY FAILED … Error Code: 63016` → خارج النافذة بلا قالب (سجّل القالب).

اختبار سريع لكامل المسار (يتجاوز الخنق): `POST /api/admin/editor-alerts/test-ai`.

## ملاحظة: تنبيهات النشر «📢 نشرنا للتو»

نفس القيد يسري على تنبيهات النشر (تُرسل نصًّا حرًّا أيضًا). إن لزم ضمان وصولها خارج النافذة،
تحتاج قالبًا معتمدًا خاصًّا بها بنفس الطريقة.
