# VARA — دخول عضوية سبق + خطة التسويق (توثيق ما قبل الإطلاق)

> **الحالة:** أفكار مُقرّة استراتيجيًا (2026-07-06)، بانتظار موك-أب ثم تنفيذ.
> **القرار الحاكم:** رعاية خفيفة **«من سبق»** (Endorsement-light) — VARA يبقى العلامة الرئيسية، وسبق تظهر كختم ثقة صغير + جسر العضوية.
> **التطبيق:** `sports app ios/SabqSports` (الاسم الداخلي `SabqSports`، الثيم أبيض + أخضر).

---

## 0) السياق والتوتر الاستراتيجي

- VARA هو تطبيق سبق الرياضي، حُوّل من **«سبق الرياضي»** إلى **VARA** بتاريخ 2026-06-29، مع **إزالة هوية سبق عمدًا** (الشعار، الـOnboarding، توحيد الثيم أبيض+أخضر)، وإضافة محرّك «توقّع VARA» (بواسون — `VaraPrediction.swift`) والذكاء السلوكي (`VaraInsights.swift`) وصفحات قانونية + حذف حساب.
- **الطلب الجديد:** استخدام **عضوية سبق** للدخول والاستفادة من الخدمات، **وتسويق VARA كأحد منتجات صحيفة سبق** لإعطائه زخمًا.
- **التوتر:** الطلبان يبدوان معاكسين لقرار التجريد. **الحل المعتمد:** لا رجوع للدمج الكامل، بل **نموذج الرعاية/الاعتماد**: VARA علامة مستقلة قوية، وسبق تمنحه المصداقية + العضوية + الزخم من الخلف، عبر **ثلاثة مواضع «من سبق» خفيفة فقط**.

---

## 1) منطقة دخول العضوية

### القاعدة: «الرياضة أولًا، الدخول سياقي» (Progressive / Guest-first)
- **لا جدار دخول** — الـOnboarding أُزيل عمدًا؛ لا نعيده. كل التصفح متاح للضيف.
- الدخول يُطلب **فقط عند لحظة القيمة** (contextual trigger)، لا عند فتح التطبيق.

### الإشارة (Indicator) — أيقونة الحساب في الشريط العلوي
| الحالة | الإشارة البصرية |
|---|---|
| ضيف (خارج) | أيقونة شخص `👤` + كلمة «دخول» خفيفة |
| عضو (داخل) | أفاتار/أحرف الاسم + نقطة خضراء صغيرة |

الموضع: ركن أعلى-يسار (RTL).

### المحفّزات السياقية (متى يظهر الـbottom sheet)
- حفظ **الفريق المفضّل** (بلوك «فريقي» موجود أصلًا).
- إرسال **توقّع VARA**.
- تفعيل **تنبيهات المباريات** (هدف / كرت / فار).
- **المزامنة** عبر الأجهزة.

### الطريقة السلسة — Bottom Sheet لا شاشة كاملة
```
┌─────────────────────────────┐
│  مرحبًا بك في VARA           │
│  سجّل بعضويتك في سبق للتوقّع │
│  والتنبيهات والمزامنة        │
│                             │
│  [  الدخول بعضوية سبق  ]    │ ← أساسي، أخضر
│  [  Apple  ]  [ Google ]    │ ← ثانوي
│                             │
│  بالمتابعة توافق على الشروط  │
│              ·من سبق·        │ ← الختم الخفيف
└─────────────────────────────┘
```
- خيار واحد بلمسة: **«الدخول بعضوية سبق»** (أساسي) + Apple + Google (ثانوي).
- الصياغة تبني الثقة: **«سجّل بعضويتك في سبق»** بدل «أنشئ حسابًا» — كثير من الجمهور عنده الحساب جاهز → احتكاك أقل + ربط ذهني بين المنتجين.

### الجسر التقني (إعادة استخدام لا بناء من الصفر)
- نفس بنية سبق للجوال: **`appMemberSessions` + Bearer token + `verifyMemberSession`** على `/api/v1`.
- **SSO:** لو المستخدم داخل بتطبيق سبق الأم على نفس الجهاز → دخول بلمسة بلا إعادة تسجيل. ولو عنده حساب سبق أصلًا → يدخل به مباشرة.
- تنبيه: لا Apple Sign-In على أندرويد (قرار سابق: احتكاك مرفوض) — زر Apple لـiOS فقط.

### مواضع «من سبق» الثلاثة (خفيفة، لا تزاحم علامة VARA)
1. **الاسبلاش:** سطر صغير تحت شعار VARA.
2. **أسفل الـbottom sheet.**
3. **تبويب «حسابي» عند الدخول:** شارة «عضو سبق» + رابط «إدارة حساب سبق».

## 2) خطة التسويق (تنفيذ الرعاية الخفيفة)

**المبدأ:** أقوى وأرخص رافعة هي **جمهور سبق الحالي** — لا تُشترى جماهير جديدة ونحن على ملايين الزيارات.

| القناة | التنفيذ |
|---|---|
| **ASO / المتجر** | العنوان الفرعي «VARA — الرياضة من سبق» + لقطة فيها الختم |
| **Cross-promo** | بلوك/بانر في قسم الرياضة على sabq.org و/sports: «VARA — تطبيق سبق الرياضي: نتائج حية وتوقّعات» + زر تثبيت |
| **Smart App Banner** | على صفحات الرياضة في sabq.org → تثبيت بلمسة لـiOS |
| **Push** | حملة للمستخدمين الحاليين (بنية الإشعارات التحريرية جاهزة على Railway) |
| **Deep Links** | كل خبر رياضي في سبق ينتهي بـ«النتيجة الحية والتوقّعات على VARA» → يفتح المباراة داخل التطبيق |
| **توقيت البطولات** | اربط الدفعة بصافرة الانطلاق: المونديال 2026 / خليجي 27 / كأس آسيا / روشن — الهبات موجودة بالكود |
| **العضوية الواحدة** | رسالة: «بعضويتك في سبق، VARA جاهز — بلا تسجيل جديد» |
| **تقاطع الولاء/النقاط** | توقّعات VARA تكسب **نقاط سبق** (نظام الولاء موجود) → يربط المنظومتين ويحفّز الارتداد |

## 3) الخطوات التالية
1. **قياس بالكود:** فتح مصدر `sports app ios/SabqSports` وتحديد المكان الدقيق لأيقونة الحساب والـbottom sheet.
2. **موك-أب بصري** (حالات الأيقونة + الـbottom sheet + مواضع «من سبق») للإقرار قبل التنفيذ.
3. **تنفيذ** ربط زر «الدخول بعضوية سبق» بـ`appMemberSessions`.

## مراجع ذات صلة
- بنية دخول جوال سبق: `appMemberSessions`, `/api/v1`, `verifyMemberSession` (Bearer، لا Passport).
- محرّكات VARA: `SabqSports/Services/VaraPrediction.swift`, `SabqSports/Services/VaraInsights.swift`.
- سياسة قفل الاسم: `firstName`/`lastName` write-once عبر المنصّات.
- الفرع العامل: `feat/sports-matches-tab-wc-center` (غير مدموج وقت كتابة هذا).
