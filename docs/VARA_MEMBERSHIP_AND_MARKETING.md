## 0) السياق والتوتر الاستراتيجي

- VARA هو تطبيق سبق الرياضي، حُوّل من **«سبق الرياضي»** إلى **VARA** بتاريخ 2026-06-29، مع إزالة هوية سبق من الواجهة الرئيسية، وإضافة محرّك «توقّع VARA» (`VaraPrediction.swift`) والذكاء السلوكي (`VaraInsights.swift`) وصفحات قانونية + حذف حساب.
- **الطلب:** عضوية سبق للدخول + تسويق VARA كمنتج من صحيفة سبق.
- **الحل المعتمد:** لا دمج كامل — نموذج رعاية خفيفة: VARA علامة مستقلة، وسبق ختم ثقة + جسر عضوية في مواضع محدودة.

## 1) منطقة دخول العضوية

### القاعدة: «الرياضة أولًا، الدخول سياقي» (Guest-first)
- **لا جدار دخول** و**لا Onboarding** — كل التصفح متاح للضيف من أول فتح.
- الدخول يُطلب **فقط عند لحظة القيمة** (contextual trigger).

### الإشارة — أيقونة الحساب في الشريط العلوي
| الحالة | الإشارة البصرية |
|---|---|
| ضيف | أيقونة شخص + كلمة «دخول» خفيفة |
| عضو | أفاتار/أحرف الاسم + نقطة خضراء صغيرة |

الموضع: ركن أعلى-يسار (RTL). منفّذ في الرئيسية ومركز المباريات.

### المحفّزات السياقية
- حفظ الفريق المفضّل / إرسال توقّع / تفعيل تنبيهات / المزامنة عبر الأجهزة.

### ورقة الدخول (Bottom Sheet)
```
┌─────────────────────────────┐
│  مرحبًا بك في VARA           │
│         ·من سبق·             │ ← الختم تحت الترويسة (الموضع 2)
│  سجّل دخولك لتحفظ فريقك…     │
│                             │
│  [ الجوال ] [ عضوية سبق ]   │
│  …حقول الدخول…              │
│  [  Apple  ]                │ ← ثانوي (iOS فقط)
└─────────────────────────────┘
```
- **لا زر Google** (قرار ب1).
- الختم يبقى **تحت الترويسة** (قرار المالك بعد معاينة 2026-07-09) — لا يُنقل لأسفل الورقة.

### الجسر التقني
- `appMemberSessions` + Bearer + `verifyMemberSession` على `/api/v1`.
- مسارات الدخول الحالية: عضوية سبق (بريد/جوال+كلمة مرور) · OTP جوال · Apple.
- **SSO من تطبيق سبق الأم:** مؤجّل (P2) — ليس ضمن جولة الختم الحالية.
- Apple لـiOS فقط (لا Apple على أندرويد — قرار سابق).

### مواضع «من سبق» (هذه الجولة)
1. **الاسبلاش:** داخل أصل `LaunchBrand` («أحد منتجات سبق») — منفّذ.
2. **ورقة الدخول تحت الترويسة:** في `SpMembershipLogin.header` («أحد منتجات · صحيفة سبق») — منفّذ؛ أُبقي مكانه الأصلي بقرار المالك بعد المعاينة.
3. ~~حسابي: رابط إدارة حساب سبق~~ — **مؤجّل**. شارة «عضو سبق» الحالية تبقى كما هي.

## 2) خطة التسويق (رعاية خفيفة)

**المبدأ:** أقوى رافعة = جمهور سبق الحالي.

| القناة | التنفيذ |
|---|---|
| **ASO / المتجر** | العنوان الفرعي «VARA — الرياضة من سبق» + لقطة فيها الختم |
| **Cross-promo** | بانر في قسم الرياضة على sabq.org |
| **Smart App Banner** | صفحات الرياضة → تثبيت iOS |
| **Push** | حملة لمستخدمي سبق الحاليين |
| **Deep Links** | خبر رياضي → المباراة داخل VARA |
| **توقيت البطولات** | المونديال / خليجي / آسيا / روشن |
| **العضوية الواحدة** | «بعضويتك في سبق، VARA جاهز — بلا تسجيل جديد» |
| **تقاطع الولاء/النقاط** | مؤجّل (P3) بعد استقرار البركة |
