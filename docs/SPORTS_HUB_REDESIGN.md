# إعادة تصميم قسم الرياضة (Sports Hub Redesign)

> **الحالة:** مكتمل ومتحقَّق منه محليًا · **الفرع:** `feat/saudi-league-hub`
> **المسار:** `/sports` · **الملف:** [`client/src/pages/SportsHub.tsx`](../client/src/pages/SportsHub.tsx)
> **آخر تحديث:** 2026-06-17

تلميع وتنظيم البوابة الرياضية العامة (`/sports`) لتكون أنظف، أرتب، وأكثر إبداعًا —
مع توحيد هويتها على **أزرق لوقو سبق** بدل الأخضر المستعار، وتصميم بطاقات مباريات
مدمجة تستغل المساحة بكفاءة أعلى.

---

## الملخّص

ثمانية أركان من التلميع + إعادة تصميم بطاقة المباراة + سكربت زرع أخبار تجريبية بصور.
كل التغييرات في **ملف واحد** (`SportsHub.tsx`) + سكربت زرع اختياري. **لا مسّ للـbackend،
لا dependencies جديدة، لا تغيير للـAPIs.**

---

## الركن 1 — توحيد الهوية على أزرق اللوقو

### المشكلة
الصفحة كانت تستخدم `emerald-*` (hue ~160) المستعارة من `WorldCup.tsx`، بينما هوية
سبق الرسمية هي **أزرق كهربائي** (`--primary = hsl(204, 88%, 53%)` = لون اللوقو).

### الحل
| كان (أخضر) | أصبح (أزرق اللوقو) |
|---|---|
| `text-success` / `bg-success` / `border-success` / `ring-success` / `from-success` | `text-primary` / `bg-primary` / `border-primary` / `ring-primary` / `from-primary` |
| `success-foreground` | `primary-foreground` |
| `bg-accent-green/30` (صناديق الأيقونات) | `bg-accent-blue/30` |

ثابت اللون المركزي:
```ts
// لمسة الهوية (accent) — أزرق اللوقو الرسمي (--primary = hsl 204 88% 53%)
const ACCENT = "text-primary";
```

### ما بقي كما هو (مقصود للتباين)
- 🟡 **أمبر** (`amber-400/500`) — لون الضيف / المرتبة الثانية. تباين دافئ مقابل الأزرق البارد.
- 🔴 **أحمر** (`red-500`) — مباشر/عاجل. اصطلاح عالمي لا يُمسّ.
- 👑 **أمبر ذهبي** للتاج (رجل المباراة).

## الركن 6 — اللمسات الإبداعية (3، كلها بلا backend)

كل اللمسات تستخدم بيانات موجودة فعلاً في `/api/sports/match/:id` (لا حاجة لتعديل الخادم).

### 6أ. شريط استحواذ بارز
في تبويب «نبض الأرقام» بنافذة المباراة، استخراج `Ball Possession` من `statistics.rows`
وعرضه كشريط ثنائي اللون بارز بالأعلى مع نسبتي الاستحواذ كأرقام كبيرة (`PossessionBar`).

### 6ب. أشرطة إحصائية متناظرة
استبدال `StatBar` (شريطان متلاصقان) بالنسخة **المتناظرة من المركز** — شريطان ينموان
من المنتصف للخارج `absolute end-1/2 rounded-s-full bg-primary` و `start-1/2 rounded-e-full bg-amber-400`.

### 6ج. جائزة «رجل المباراة»
عند توفر `xG` (Expected Goals)، صف مميّز بتاج `Crown` لصاحب أعلى xG:
```tsx
<div className="bg-gradient-to-l from-amber-500/15 to-transparent ring-1 ring-amber-500/30">
```
يختفي بسلاسة إن لم تتوفر xG للبطولة.

> **مؤجّل (يحتاج backend):** مخطط الزخم الحي (momentum) + الملعب التكتيكي 2D للتشكيلات —
> لأن `/api/sports/match/:id` لا يرجّع `trends` ولا `grid` للاعبين.

## إعادة تصميم بطاقة المباراة (MatchCard)

### المشكلة
البطاقة القديمة تأخذ ~140px ارتفاع، عمودان فقط (`sm:grid-cols-2`) — مساحة كبيرة لكل مباراة.

### الحل: صف مدمج
كل مباراة في **سطر أفقي واحد** ~56px:

```
┌──────────────────────────────────────────┐
│ الهلال    [شعار]  2-1  [شعار]   النصر    │ ← سطر واحد
│ الجولة 5              ● 66' مباشر        │ ← سطر الحالة رفيع
└──────────────────────────────────────────┘
```

التغييرات:
- `rounded-2xl p-4` → **`rounded-lg px-3 py-2`** (أكثر إحكامًا).
- شعار بدائرة 40×40px → **شعار مباشر 20×20px**.
- النتيجة `text-2xl` → **`text-sm`** داخل صندوق رمادي خفيف بالوسط.
- الشبكة `sm:grid-cols-2` → **`sm:grid-cols-2 lg:grid-cols-3`**.
- مؤشر المباشر: شريط أفقي فوق → **شريط عمودي على اليمين**.
- تمييز الفائز/الخاسر: الفائز `text-foreground`، الخاسر `text-muted-foreground`.

### النتيجة
**6 مباريات الآن في مساحة بطاقتين قديمتين** (~3× كثافة أعلى).

## سكربت زرع الأخبار التجريبية

### المشكلة
الأخبار الرياضية المحلية كلها بلا صور (`imageUrl = NULL`)، فلا تتضح معاينة التصميم.

### الحل
[`scripts/seed-sports-images.ts`](../scripts/seed-sports-images.ts) — يزرع 10 أخبار
رياضية بصور حقيقية من **Picsum Photos** (مجاني، 1280×720، seed ثابت لكل خبر).

### الاستخدام
```bash
DATABASE_URL="postgresql://alialhazmi@localhost:5432/sabq_dev" \
DB_DRIVER=pg \
npx tsx scripts/seed-sports-images.ts
```

> ⚠️ **DB_DRIVER=pg إجباري** للـPostgreSQL المحلي (الافتراضي `neon` يحاول WebSocket).
> الحماية: يرفض التنفيذ ضد `DATABASE_URL` تحتوي `prod`/`production` ما لم تُضف `FORCE_SEED=1`.

### آمان
- يضيف فقط (INSERT)، لا يمسّ الأخبار الموجودة.
- ذو `slug` مسبوق بـ`seed-sports-` (سهل الحذف لاحقًا):
  ```sql
  DELETE FROM articles WHERE slug LIKE 'seed-sports-%';
  ```

### ملاحظة: ترتيب `displayOrder`
الـendpoint يرتّب بـ`displayOrder DESC` أولاً. الأخبار القديمة لها قيم ضخمة (~1.78 مليار =
طوابع زمنية). لذا السكربت يضع `display_order` أعلى من القمة الحالية:
```sql
UPDATE articles SET display_order = (SELECT MAX(display_order) FROM articles) + 10
WHERE slug LIKE 'seed-sports-%';
```

## نقاط فنية مهمة

### الكاش الخادمي
الـendpoint `GET /api/categories/:slug/articles` يختبئ خلف `withSWR` (TTL = دقيقتان).
بعد الزرع، الكاش القديم يُخدم حتى انتهاء TTL. للحصول على معاينة فورية:
- أعِد تشغيل السيرفر (يفرّغ الكاش الخادمي في الذاكرة)، أو
- انتظر ≤2 دقيقة.

### هجرة الألوان عبر `perl`
لاستبدال آمن لكلمة `success` كاملة (حدّ الكلمة) في كل سياقاتها دفعة واحدة:
```bash
perl -i -pe 's/\bsuccess\b/primary/g' client/src/pages/SportsHub.tsx
```
(تُعالج `success-foreground` يدويًا قبلها لتفادي التضارب.)

### التوكنز المستخدمة
كلها معرّفة في `client/src/index.css` بالوضعين الفاتح والداكن:
- `--primary` (107/291) و`--primary-foreground` (109).
- `--accent-blue` (127) — معرّفة في `:root`، تسقط في `.dark` (مقبولة بنسبة `/30`).
